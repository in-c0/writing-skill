Install the skill

Three skills ship from one repo. Start with StoryScope; it led every genre in this round.

Uses the open skills.sh installer, which works with Claude Code, Codex, Cursor and other agents that read SKILL.md.

$ npx skills add in-c0/writing-skill --skill storyscope -g
$ npx skills add in-c0/writing-skill --skill writing-skill-storyscope -g

Drop -g to install into the current project only. Scoring a story needs pip install xgboost numpy.

  1. Download a skill: storyscope.zip writing-skill-storyscope.zip writing-skill.zip
  2. In the Claude app, open your settings, find Skills, and upload the zip.
  3. Ask for a story, a post or some copy. The skill loads on its own when the task fits.
$ git clone https://github.com/in-c0/writing-skill && cp -r writing-skill/skills/storyscope ~/.claude/skills/

Any agent that reads skill folders works the same way: copy skills/<name>/ into its skills directory.

How this was measured

Six briefs: two journal posts, two pieces of sales copy, two short stories. Each brief was written four times by the same model in fresh sessions: no skill, writing-skill, writing-skill + StoryScope, and StoryScope alone. Two AI editors scored all four pieces per brief without knowing which was which. Stories were also annotated on the paper's 304 features and run through its released classifier.

This is a small, early benchmark: twelve judgements per setup, and the judges belong to the same model family as the writer. The classifier was trained on 5,000-word stories annotated by a different model, so its absolute numbers here are not comparable to the paper; read it as a relative signal. Human picks are what make the result trustworthy, which is why the judging rounds above exist.

StoryScope: Russell, Rajendhran, Pham, Iyyer, Wieting (2026), arXiv:2604.03136, data and models under MIT. Code and every raw output: github.com/in-c0/writing-skill.
