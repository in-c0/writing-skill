## This repo
- Read `SKILL.md` before substantial writing; `CHECKLIST.md` for final review; `extensions/WRITTEN_SPOKEN.md` for spoken/audiobook/equations/figures. Default: write for the reader; preserve the user's voice; rules-first generation (draft→review and hybrid are experimental modes).
- `skills/storyscope/` is hand-maintained; `skills/writing-skill*/` are built by `python scripts/build_skills.py` from the root rulebook + `skills/_src/` — edit sources, rebuild. Benchmark: `python benchmark/tools/aggregate.py` refreshes `results.json`, `README.md`, `benchmark/BENCHMARK.md`.
