# Shot and review schema

| field | required |
|---|---|
| shot_id | yes |
| in_sec, out_sec | yes; non-overlapping, sum matches runtime |
| dramatic_function | yes |
| protagonist_goal_and_constraint | yes |
| audience_belief_before | yes |
| action_and_consequence | yes |
| reveal_or_reversal | when applicable |
| composition_lens_camera_blocking | yes |
| dialogue_voiceover | if any |
| music_cue_id, sfx_cue_ids, silence | yes |
| brand_and_product_exposure | yes |
| proof_status | VERIFIED / PROTOTYPE / CONCEPT / UNKNOWN |
| asset_source_and_license | if asset used |
| transition_and_exit_question | yes |

## Adversarial review
Score 0–4, citing specific shots: causal continuity, surprise earned, protagonist agency, recognizability, differentiated product need, pacing, comprehension, brand recall, CTA, production feasibility, claims truthfulness, accessibility and audio clarity.
A high mean score does not override a failed factual-claims or rights gate. Test against a phone, watch and no-product counterfactual.
