What to compare

Do not ask only which version is more polished. Look at clarity, naturalness, usefulness, voice preservation, reader effort, concreteness, recoverability, rhetorical over-engineering, rhythm, genre fit, and whether you would actually keep reading.

Speed: Quick mode keeps each result short, Hybrid uses one model pass instead of two, and completed results are cached while the brief and length stay unchanged.

Experimental detail: Draft → review starts from the exact Baseline output for the current brief. The model and decoding settings stay fixed; the prompting workflow is what changes.

Browser constraint: the live lab uses a condensed, faithful digest of the public rulebook so a small local model can run the comparison within a practical context window. The full rules remain available in the GitHub repository.

Model: SmolLM2-360M-Instruct ONNX, q4 quantized for in-browser inference with Transformers.js. The browser demo defaults to CPU/WASM rather than requiring WebGPU.
