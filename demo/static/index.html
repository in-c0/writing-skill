Experimental notes

Baseline: no added writing-style instructions. Rules first: a compact digest of the public rulebook is supplied before drafting. Draft → review: the exact baseline is revised. Hybrid: core principles guide the first draft, followed by a separate review pass.

The live browser lab uses the same q4-quantized SmolLM2-360M-Instruct ONNX model for every stage. CPU/WASM is used for compatibility. There is no artificial short-word limit; output length is controlled by the token budget in Stage 2.
