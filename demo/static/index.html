What to compare

Do not ask only which version sounds more polished. Look at clarity, naturalness, concreteness, reader effort, useful repetition, rhythm, genre fit, and whether you would actually keep reading.

Rules first is the production default. The other modes are included to test that default, not to imply that every writing task should run through several variants.

The rulebook is a diagnostic tool, not a scorecard. Sometimes the baseline control will still expose something useful about the default.

Generation is handled by the project owner's Vercel backend through AI Gateway. The public page requires no account or API key from the reader. Requests still leave this page for hosted inference, so do not submit private or sensitive text.

The hosted model allows only a few generations every few minutes across all visitors. When that happens, the stage waits and retries on its own for a few minutes; earlier results stay on the page.
